# E-Library Management System

A Laravel-based electronic library management system designed to organize digital library operations through a structured web application.

## 🎯 Project Overview

This project demonstrates practical backend and full-stack development using Laravel, PHP, role-based permissions, database-driven workflows, and a modern application structure.

## 🛠️ Technology Stack

- **Backend:** PHP, Laravel 11
- **Database:** SQLite / relational database via Laravel
- **Authentication & Authorization:** Laravel UI, Spatie Laravel Permission
- **Development Tools:** Composer, Laravel Sail, PHPUnit, Laravel Pint

## ✨ Technical Highlights

- Laravel MVC architecture
- User authentication
- Role and permission management
- Database migrations and seeders
- Structured backend application design
- Automated application setup and testing support
- Clean, maintainable Laravel project structure

## 🚀 Getting Started

### Requirements

- PHP 8.2+
- Composer
- Node.js and npm
- SQLite or another supported database

### Installation

```bash
git clone https://github.com/chris-favour49/e-library-system.git
cd e-library-system
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run build
php artisan serve
```

Configure your `.env` file before running the application.
